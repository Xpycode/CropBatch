## Decisions
- **Toolbar stays system-style for now** — the Penumbra titlebar injection pattern requires `.hiddenTitleBar` which breaks CropBatch's GeometryReader-based canvas layout. Proper migration needs dedicated investigation.
- **AppKitSegmented for sidebar only** — safe since it's not in the toolbar/content area layout chain
- **Cookbook needs update** — titlebar injection pattern should note `.hiddenTitleBar` is a prerequisite, not optional

## Lessons Learned
- `.windowStyle(.automatic)` + `.toolbar {}` → SwiftUI uses toolbar items for safe area calculation. Removing all items breaks GeometryReader sizing in content views
- `.windowStyle(.hiddenTitleBar)` removes this dependency but introduces its own layout behavior that needs careful testing
- `NSViewRepresentable` as `.background()` on the content view can interfere with layout
- `@Environment(AppState.self)` crashes in injected `NSHostingView` — separate view hierarchy has no inherited environment

## Post-Session Discovery: Penumbra's Actual Pattern

Investigated why Penumbra works — it does NOT use the cookbook's titlebar injection pattern. It uses:
```
.windowStyle(.hiddenTitleBar)   // removes title bar chrome
.toolbar { real items }          // KEEPS real toolbar items
.toolbarRole(.editor)            // editor layout
+ FCPToolbarButtonStyle          // flat buttons — works because .hiddenTitleBar reduces chrome enforcement
```

Key insight: Penumbra keeps real `.toolbar {}` items (doesn't remove them). The `FCPToolbarButtonStyle` renders correctly under `.hiddenTitleBar` without needing NSView injection. The cookbook's titlebar injection was an unnecessary escalation.

**CropBatch's problem:** When we tried `.hiddenTitleBar`, we ALSO removed toolbar items (replaced with injection). The removal broke layout. The fix path is: `.hiddenTitleBar` + keep toolbar items + `FCPToolbarButtonStyle`.

**Remaining unknown:** CropBatch's `CropEditorView` uses GeometryReader for the main canvas. Penumbra uses fixed-height sections (no GeometryReader in main content). This may cause sensitivity to `.hiddenTitleBar` safe area changes that Penumbra doesn't hit.
