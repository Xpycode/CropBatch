## Decisions
- **`UIDesignRequiresCompatibility = true` is mandatory for all macOS apps** — without it, macOS forces compatibility-mode chrome on toolbar items
- **Flat toolbar is v1.5, not v2.0** — the fix was trivial once the root cause was found
- **Cookbook updated** — this is now Section 0 of the App Shell Standard

## Lessons Learned
- The real blocker was an Info.plist key, not SwiftUI code — invisible in code diffs
- Previous session (2026-04-05-b) tested 5 SwiftUI approaches but never checked project configuration
- Cross-project config comparison (deployment target, Info.plist, build settings) found the answer in minutes
- Always diff the full project setup, not just the Swift code
