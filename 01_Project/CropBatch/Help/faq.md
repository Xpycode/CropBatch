# FAQ

**Does the crop apply to every image?**
Yes — your crop and effect settings are applied to all imported images, so you can process a whole batch identically.

**Can I overwrite the original files?**
Yes. Use **Save in Place** to write back to the source files, or choose Overwrite when exporting to the same folder.

**Why did my format switch to PNG?**
Corner Radius needs transparency, so enabling it automatically exports as PNG.

**What image formats are supported?**
Import common image types; export to PNG, JPEG, HEIC, TIFF, or WebP.

**How do I redact something?**
Use the Blur tool (**B**) to add blur regions over sensitive areas, with adjustable intensity.

**Can I keep the app up to date?**
Yes — use **CropBatch ▸ Check for Updates…**.
