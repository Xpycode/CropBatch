# Keyboard Shortcuts

## Files
| Shortcut | Action |
| --- | --- |
| ⌘O | Import Images… |
| ⇧⌘E | Export… |
| ⇧⌘C | Copy Cropped Image |

## Navigation
| Shortcut | Action |
| --- | --- |
| ⌘↑ / ⌘↓ | Previous / Next image |
| ⌘A | Select All |
| ⇧⌘A | Deselect All |
| ⌘⌫ | Remove selected |

## Cropping
| Shortcut | Action |
| --- | --- |
| ⇧ + Arrow | Adjust crop by 1px |
| ⇧⌃ + Arrow | Adjust crop by 10px |
| ⇧⌥ + Arrow | Uncrop (expand) |
| ⌘R | Reset Crop |

## View
| Shortcut | Action |
| --- | --- |
| ⌘1 / ⌘2 / ⌘3 / ⌘4 | Actual Size / Fit / Fit Width / Fit Height |
| ⌘B | Show Before/After |
| S | Toggle Snap-to-Edge |
| B | Toggle Blur tool |
