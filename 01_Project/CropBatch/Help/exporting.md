# Exporting & Formats

When your crop and effects look right, export the whole batch.

- **Export All** processes every imported image with the current settings.
- **File ▸ Export…** (⇧⌘E) lets you pick a destination folder.
- If files already exist in the destination, CropBatch asks whether to **Overwrite** or **Rename** (adds `_1`, `_2`, …).

## Save in Place

Prefer to overwrite the originals? **Save in Place** writes back to the source files directly — no folder picker needed.

## Formats

Export to **PNG, JPEG, HEIC, TIFF, or WebP**. (Corner Radius forces PNG, since it needs transparency.)

## Resize

Optionally resize on export:

- Exact size
- Max width / max height (fit within bounds)
- Percentage scaling

## Naming

Keep original names with a suffix, or use a naming pattern. The estimated output file size is shown for the current image and the whole batch.

## Copy a single image

**Edit ▸ Copy Cropped Image** (⇧⌘C) copies the active cropped image to the clipboard without exporting.
